My Journey Learning HTML

HTML stands for HyperText Markup Language. It is used to structure content on websites, including headings, paragraphs, images, and links.

Learning HTML is an important first step in web development. It helps me understand how webpages are created and organised.

What I Am Learning

  • HTML tags and elements
  • Creating links between webpages
  • Adding images and lists

Steps to Build a Webpage

  1. Create an HTML file.
  2. Write the HTML structure and content.
  3. Open the page in a browser and test it.
